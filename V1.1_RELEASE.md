# V1.1 — federated national registry

MNCSdb now focuses on council oversight. Its default workspace removes daily athlete, team, fixture and result management. Those records and earlier modules remain in the source/database for compatibility; they are not deleted.

Association sites send competitions, performance summaries and private council submissions. MNCS controls connection creation, rotation and pause, competition review and council decisions. Receipt refresh sends decisions back to the association site. The Darts addon adds the first site-side sharing interface without replacing its existing league system.

## Included

- Complete transactional SQL installer, including V1.1 connector tables, guarded RPCs, role policies and dossier linking.
- MNCS exchange gateway and Darts server adapter.
- National workspace navigation, connection management, competition review, incoming drafts and performance panels.
- Source-linked annual reports/nominations with existing private PDF requirements.
- Direct council inbox delivery for complete funding/travel/clearance/other requests.
- Stable message IDs, duplicate protection, revision checks and preserved competition approval snapshots.
- Public summary allowlists, explicit opt-in athlete names and private nomination birth dates.

Official awards still use the existing judge ballots and certification process. Public polls contribute zero to official scoring. Automatic tournament generation remains an association-side operational concern; the Darts addon does not introduce a new tournament engine.

## Limits

The pilot supports current 2026 regional Darts league performance data. Custom competition registration is supported, but other event statistics need their own adapters. No shared login, background scheduler, universal cross-sport ranking, automatic athlete identity matching or automatic PDF transfer is included. Up to 500 receipts are returned per connection. Rankings need the association to review source names and data quality.

No production deployment was performed. The Darts Netlify dashboard was inaccessible, and its complete source was unavailable. The separate addon ZIP must be merged into that source, never deployed alone. Follow START_HERE.md and integrations/darts/README.md.
