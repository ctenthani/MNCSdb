# MNCS V0.9 verification

Verification performed on 2 October 2026, locally. No live accounts, production
SQL, Netlify settings or production deployment were changed by this work.

## Automated results

**51 tests passed, no failures or skipped tests** with the optional PostgreSQL
and DOM runners enabled:

    PGLITE_MODULE=/path/to/@electric-sql/pglite/dist/index.js JSDOM_MODULE=/path/to/jsdom node --test tests/*.cjs tests/*.mjs

The runtime dependencies used were @electric-sql/pglite 0.3.14 and the existing
jsdom installation. These are optional test tools, not website dependencies.
Without the environment paths, the PostgreSQL and DOM integration tests report
skips; ordinary tests can run with Node alone. Netlify requires no npm build.

### PostgreSQL execution

The complete SQL installer was executed in PGlite's PostgreSQL engine against
local Supabase-style auth/storage schemas and roles, then repeated. This checks
actual SQL/function execution, beyond merely parsing migration syntax.

Fourteen database subtests plus their parent test verified:

- Repeatable full installation, including rerun after data exists.
- Reviewer draft-write denial and association scoring-rule denial.
- Admin-only rule creation, descending points, immutable policies.
- Tenant isolation and prevention of association self-approval.
- Private masters denied to anonymous users; DOB absent from public projections.
- Approved dependencies, result-date rules and placing/outcome validation.
- Database-produced rankings, duplicate prevention and joint ties.
- Best N competition cap and available/counting counts.
- Approved snapshots retained during corrections; append-only RPC audit history.
- Consent withdrawal removes public athlete profiles and anonymises result labels.
- Approved fixture dependencies, same-time team conflict rejection and public allowlist.
- Closed nomination-window rejection and registered junior nomination submission.
- Archive dependency protection and removal from public results.
- Existing account profiles and sports history retained on installer rerun.

PGlite simulates the database engine and roles. It does not run Supabase Auth,
PostgREST, real JWT verification, Storage, Netlify or multi-client concurrency.
Association transaction locking is present in SQL but concurrency was not load-tested.
