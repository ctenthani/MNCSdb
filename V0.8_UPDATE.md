# MNCS Registry v0.8

Public shell polish on top of the v0.7 workspace, awards, accounts and SQL installer.

- Navigation lists Dashboard, Associations, Players, Events, Results, Awards and Workspace in one order on desktop and mobile.
- Version badge and footer read v0.8.
- Live Supabase rows replace sample rows only when that collection has data. Sample athletes are not mixed with live association IDs, so the public site does not show unmatched clubs.
- Banner text states whether the page is on sample data, a mixed live/sample view, or a fully connected registry.
- Account creation, password reset, association editing, awards screening and reporting are unchanged.

Deploy the whole folder. Keep SITE_ORIGIN, SUPABASE_URL and the private function key as in v0.7.
